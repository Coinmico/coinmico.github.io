# Coinmico

[Coinmico](https://coinmico.com) is an independent cryptocurrency market data and analytics platform. It measures prices, market capitalisation and volume from the exchanges and blockchains it indexes itself.

- Live crypto prices and rankings: https://coinmico.com
- Exchange rankings: https://coinmico.com/exchanges
- Derivatives and liquidations: https://coinmico.com/liquidations
- Whale tracker: https://coinmico.com/whales
- Fear & Greed Index: https://coinmico.com/fear-and-greed
- Methodology: https://coinmico.com/methodology
- Android app: https://play.google.com/store/apps/details?id=com.coinmico.app

This repository hosts the Coinmico project page on GitHub Pages.
